# Logos

Põe aqui o logótipo de quem assina os criativos:

- `logo-completo.png`, logótipo com o nome, fundo transparente, pelo menos 1200px de largura.
- `logo-icone.png`, só o símbolo, fundo transparente, quadrado.

Se for um cliente teu, cria uma subpasta com o nome dele:
`logos/<cliente>/logo-completo.png`.

Regra: o logótipo nunca se desenha à mão nem se recria em SVG a olho. Usa sempre
o ficheiro original que a marca te deu. Se não tiveres, pede. Um logótipo
"parecido" numa peça que vai para o cliente é pior do que não ter logótipo.
